# backend/ — зона разработчика A

API на FastAPI. Читает готовые файлы из `data/` (DuckDB в режиме чтения) и отдаёт ответы
строго по контракту `contract/openapi.yaml`.

Задачи из ТЗ: A6 (каркас, `/health`, `/meta`, `/calendar`), A11 (остальные эндпоинты, лимиты, ошибки), A13 (деплой).

Правила:

- Ответы должны проходить проверку по схеме контракта. Примеры правильных ответов — в `contract/examples/`.
- Ключ `FIRMS_MAP_KEY` и другие секреты читаются из переменных окружения (см. `.env.example` в корне).
- Здесь свой `pyproject.toml`. CI: `.github/workflows/backend.yml`.
