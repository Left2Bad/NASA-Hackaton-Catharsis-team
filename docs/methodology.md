## 1. Задача

Свести записи MODIS (с ноября 2000 года) и VIIRS (с января 2012 года) в один согласованный ряд,
выраженный в «эквиваленте VIIRS Suomi NPP».

## 2. Данные

_Заполнить: какие файлы FIRMS использованы, за какие годы, сколько точек по сенсорам._

## 3. Подготовка

_Заполнить: фильтр достоверности, фильтр типа источника, маска постоянных источников, сетка 0,1°._

## 4. Калибровка

Коэффициент для группы (ячейка c, календарный месяц m) — отношение сумм на периоде перекрытия:

```text
k(c, m) = сумма точек Suomi NPP / сумма точек MODIS      за 2012–2020
H(c, t) = k(c, m(t)) × M(c, t)
```

_Заполнить: иерархия групп, порог выборки, два набора коэффициентов (Terra + Aqua, только Terra),
коэффициенты NOAA-20 → Suomi NPP, интервалы неопределённости._

## 5. Сборка ряда

| Период | Ведущий источник | Преобразование |
| --- | --- | --- |
| ноябрь 2000 – июль 2002 | MODIS Terra | × коэффициент «только Terra» |
| август 2002 – январь 2012 | MODIS Terra + Aqua | × коэффициент «Terra + Aqua» |
| февраль 2012 – октябрь 2026 | VIIRS Suomi NPP | без преобразования (эталон) |
| с ноября 2026 | VIIRS NOAA-20 | × коэффициент NOAA-20 → Suomi NPP |

## 6. Проверка качества

_Заполнить результаты четырёх тестов: отложенные годы 2021–2025, шов 2012 года, шов ноября 2026,
график «до и после» для трёх показательных регионов._
